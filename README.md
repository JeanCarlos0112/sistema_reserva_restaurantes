### 📖 About the Project

This personal project is being developed to serve a **medium-sized restaurant**. It is designed as a robust web service architecture.

Currently, the project is in the **API construction phase**. The main goal is to provide a solid Back-end using **Java Spring Boot** and **JPA** to handle data persistence and business logic.

**Future Roadmap:**
The Front-end will be developed subsequently using **React** and **Tailwind CSS** to consume this API.

---

### 🔎 Technical Details

This API follows the RESTful architecture pattern.
* **Back-end:** Java Spring Boot
* **Database:** Implemented using JPA (Java Persistence API) / Hibernate.
* **Architecture:** MVC (Model-View-Controller) layers adapted for REST APIs.

It implements standard **[CRUD](https://developer.mozilla.org/en-US/docs/Glossary/CRUD)** operations (Create, Read, Update, Delete) for managing reservations, customers, and tables.

### 🗃️ Dependencies & Tools

To run this project, you will need:

* **[Java JDK 17](https://www.oracle.com/java/technologies/downloads/)** (or higher)
* **[Maven](https://maven.apache.org/)** (usually included via the wrapper `./mvnw`)
* **An IDE** (IntelliJ IDEA is recommended, but VS Code or Eclipse work too)
* **Postman/Insomnia** (Optional, for testing the API endpoints)
